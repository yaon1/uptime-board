# Changelog

## [0.2.0] — 2026-10-20

### Добавлено
- Проверки: DNS, ожидаемые коды и ключевое слово для HTTP, срок TLS-сертификатов, явный сбой heartbeat (`/fail`).
- Алерты только после N неудач подряд, плановые работы, отключение уведомлений и пауза для отдельного монитора.
- Каналы: Slack, подписанные вебхуки, несколько каналов одновременно.
- Страница статуса: группы, инциденты, график времени ответа, объявления о работах, описание, RSS.
- Интеграции: `/metrics` для Prometheus, SVG-бейджи, экспорт/импорт, CSV истории.
- Веб-админка `/admin`.
- ESLint, Prettier, typecheck и smoke-тест в CI; релиз образа по тегу.

### Исправлено
- Миграция типов мониторов без потери истории (пересоздание таблицы при выключенных внешних ключах).
- Нет «восстановления» без «падения» после плановых работ.
- Бейджи доступны по `/badge/:id.svg`.

## [0.1.0]

- HTTP, TCP и heartbeat-проверки, Telegram, страница статуса за 90 дней.
