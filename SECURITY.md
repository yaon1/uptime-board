# Безопасность

Об уязвимостях сообщайте через [приватный advisory](https://github.com/yaon1/uptime-board/security/advisories/new).

- `NUXT_ADMIN_TOKEN` даёт полный контроль над мониторами: длинная случайная строка, только через HTTPS.
- Токены heartbeat — секреты: кто знает URL, может отправить ложный «успех». Не публикуйте их и пересоздавайте монитор при утечке.
- Монитор делает HTTP-запросы туда, куда его направили: не давайте admin-доступ тем, кто не должен сканировать вашу внутреннюю сеть.
